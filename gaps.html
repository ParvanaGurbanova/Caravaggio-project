1. Identification of the First Gap

After the analysis performed in Query 4, we investigated whether the cultural property “Vocazione di S. Matteo” (Caravaggio) includes any semantic information related to its commissioning. In cultural heritage datasets, commissioning information is important because it identifies the entity responsible for funding or ordering the artwork.

The aim of this step was to verify whether such a relation is explicitly represented in the ArCo knowledge graph.

Methodology

To test the presence of commissioning data, we used an ASK SPARQL query, which checks whether a triple exists without returning results. We specifically searched for the predicate a-cd:hasCommittent.

SPARQL Query (ASK)

PREFIX a-cd: <https://w3id.org/arco/ontology/context-description/>
PREFIX arco: <https://w3id.org/arco/ontology/arco/>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>

ASK WHERE {
  <https://w3id.org/arco/resource/HistoricOrArtisticProperty/1200705423>
  a-cd:hasCommittent ?committent .
}

Result

The query returned false.

This confirms the absence of commissioning-related relations in the dataset, indicating that the commissioning context is not explicitly modeled for this cultural property.

2. Identification of the Second Gap — Missing Depicted Subjects

After identifying that commissioning information was missing, we continued our investigation by analysing whether the cultural property contains semantic information describing the subjects represented in the painting.

Representing depicted subjects is an essential aspect of cultural heritage knowledge graphs because it enables semantic search, comparison between artworks, and the identification of cultural properties depicting the same people, events, or religious themes.

The ArCo ontology models this information through the class a-cd:Subject and the property a-cd:hasSubject. Therefore, we investigated whether the selected artwork was already linked to one or more semantic subject resources.

Methodology

To verify whether subject information was already represented, we executed an ASK SPARQL query. Unlike a SELECT query, an ASK query simply checks whether at least one matching triple exists in the knowledge graph and returns either true or false.

Specifically, we searched for any relationship connecting the cultural property to a semantic subject through the property a-cd:hasSubject.

SPARQL Query (ASK)

PREFIX a-cd: <https://w3id.org/arco/ontology/context-description/>

ASK WHERE {

<https://w3id.org/arco/resource/HistoricOrArtisticProperty/1200705423>

a-cd:hasSubject ?subject .

}

Result

The query returned false.

Discussion

The result indicates that the selected cultural property is not linked to any semantic subject resource through the property a-cd:hasSubject.

However, The Calling of Saint Matthew clearly depicts several important biblical figures, including Jesus Christ, Saint Matthew, Saint Peter, and a group of tax collectors. Since none of these entities are represented as semantic subjects, the artwork cannot easily be connected with other cultural properties depicting the same iconography.

This missing semantic information represents an important knowledge gap in the ArCo Knowledge Graph. In the following phase of the project, Large Language Models will be used to identify the depicted subjects from reliable textual descriptions. The extracted knowledge will then be transformed into RDF triples using the existing ArCo ontology by creating a-cd:Subject resources linked through a-cd:hasSubject.

3. Identification of the Third Gap — Missing English Label Verification

The aim of this step was to verify whether the cultural property “Vocazione di S. Matteo” is also represented in the ArCo knowledge graph using its English title, “The Calling of Saint Matthew”.

In particular, we wanted to check whether querying the dataset using the English label would return a positive match in SPARQL.

Methodology

To test this, we executed an ASK SPARQL query to verify whether any resource in the dataset contains the English label.

SPARQL Query (ASK)

PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>

ASK {
  ?work rdfs:label ?label .
  FILTER(LANG(?label) = "en")
  FILTER(?label = "The Calling of Saint Matthew")
}

Result

The query returned: FALSE.

This result highlights a multilingual representation gap in the dataset. Although ArCo provides structured and rich metadata for the artwork, the labeling is not consistently available in English.

As a result, the English title cannot be used directly to retrieve the resource via a label-based SPARQL query.
