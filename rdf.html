1. RDF Triples Construction using ArCo Ontologies — Commission

Could you create RDF triples using ArCo ontologies for the following information: “The original commission for The Calling of Saint Matthew by Caravaggio came from the Contarelli Chapel patronage established by Cardinal Matthieu Cointerel (Matteo Contarelli).” Knowing that: IRI of the cultural property (HistoricOrArtisticProperty): https://w3id.org/arco/resource/HistoricOrArtisticProperty/1200705423 The commission information refers to a patronage/commissioning relationship between a cultural property and an agent (commissioner/patron) The commissioner “Cardinal Matthieu Cointerel (Matteo Contarelli)” is not present in ArCo, so we need to propose a custom IRI for this agent The commission should be represented using an ArCo context-description property related to commissioning or patronage (if available in the ontology), otherwise a generic agent–cultural property relationship from the ArCo context-description module should be used Also, please build the corresponding SPARQL CONSTRUCT query. Let’s think step by step.

Below is a clean way to model the statement in ArCo-style RDF, using the context-description module and introducing a lightweight commissioning/patronage event to represent the relationship between the cultural property and the patron.

1. Entities

Cultural property (Caravaggio, The Calling of Saint Matthew)
https://w3id.org/arco/resource/HistoricOrArtisticProperty/1200705423

Proposed agent IRI (not in ArCo)
We mint a stable URI for the patron:
https://w3id.org/arco/resource/Agent/Cardinal_Matthieu_Cointerel

2. Modeling choice (ArCo pattern)

Since ArCo typically represents historical relations (like commissions, ownership, attribution) through the context-description module, we model the commission as a contextual event:

Type: CommissionAttributionEvent (specialization of contextual event)

Links:
- cultural property → event
- agent (patron) → event (as commissioner/patron)

This avoids forcing a direct agent–work link and preserves provenance structure.

5. Notes on design choices

The event-centric modeling aligns with ArCo’s emphasis on contextualized cultural heritage facts.

The agent is modeled as a patron/commissioner role via participation in the event rather than a direct property link.

The event URI is deterministically derived from the work URI to ensure reproducibility.

Gemini

To accurately model this relationship using the ArCo (Architecture of Context) Ontologies, we need to rely on the context-description module (a-cd). As shown in the ontology documentation, ArCo represents commissioning as an n-ary relation through the class a-cd:Commission (which is a subclass of a-cd:Interpretation).

3. RDF Enrichment — Missing English Label (SPARQL CONSTRUCT)

Task

Generate a SPARQL CONSTRUCT query using the ArCo ontology to enrich the knowledge graph with missing English labels for an existing cultural property.

Background

An ASK query returned FALSE, indicating that the English label "The Calling of Saint Matthew" is not explicitly available in the ArCo Knowledge Graph. This reveals a multilingual labeling gap that should be addressed through RDF enrichment.

Resource Information

  • Catalogue Record:
    https://w3id.org/arco/resource/CatalogueRecordOA/1200705423
  • The catalogue record describes an existing HistoricOrArtisticProperty.
  • The enrichment must be applied to the cultural property linked from the catalogue record, not to the catalogue record itself.

Knowledge to Add

  • Preferred English label: "The Calling of Saint Matthew"
  • Alternative English labels:
    • "The Calling of St. Matthew"
    • "The Call of Saint Matthew"
    • "The Vocation of Saint Matthew"
    • "The Calling of Levi"

Requirements

  • Retrieve the existing cultural property using a-cat:describesCulturalProperty.
  • Do not create any new catalogue record or cultural property.
  • Use rdfs:label for the preferred English label.
  • Use skos:altLabel for the alternative English labels.
  • Return the result as a SPARQL CONSTRUCT query.

SPARQL CONSTRUCT Query

PREFIX a-cat: 
PREFIX arco: 
PREFIX rdfs: 
PREFIX skos: 

CONSTRUCT {
  ?cp rdfs:label "The Calling of Saint Matthew"@en .
  ?cp skos:altLabel "The Calling of St. Matthew"@en .
  ?cp skos:altLabel "The Call of Saint Matthew"@en .
  ?cp skos:altLabel "The Vocation of Saint Matthew"@en .
  ?cp skos:altLabel "The Calling of Levi"@en .
}
WHERE {
  
    a-cat:describesCulturalProperty ?cp .

  ?cp a arco:HistoricOrArtisticProperty .
}
