Query 1

We began with a broad survey to obtain all Cultural Properties related to Saint Matthew, without limiting the author. The goal was to understand how the subject is represented in ArCo and which works are related to it.

We used FILTER(REGEX(...)) to capture variations: “San Matteo”, “vocazione”, “simbolo di San Matteo”. DISTINCT was used to eliminate duplicates. ?cp = Cultural Property, ?label = title. 
PREFIX rdfs: 
PREFIX arco: 

SELECT DISTINCT ?cp ?label
WHERE {
 ?cp a arco:HistoricOrArtisticProperty ;
     rdfs:label ?label .

 FILTER(REGEX(?label, "san matteo|vocazione|simbolo", "i"))
}
The dataset includes paintings, sculptures and decorative works related to Saint Matthew, by multiple artists (e.g. Antonio Cifrondi, Rutilio Manetti). It is thematically relevant but not filtered by author, showing that thematic search alone is not sufficient.

Query 2 — Author-level filtering (initial attempt)

We improved the query by including author information to isolate Caravaggio-related works.

Used a-cd:hasAuthor and REGEX on author labels (“merisi”, “caravaggio”). Also filtered labels for “vocazione” and “san matteo”. 
PREFIX rdfs: 
PREFIX arco: 
PREFIX a-cd: 

SELECT DISTINCT ?cp ?label ?authorLabel
WHERE {
 ?cp a arco:HistoricOrArtisticProperty ;
     rdfs:label ?label ;
     a-cd:hasAuthor ?author .

 ?author rdfs:label ?authorLabel .

 FILTER(
   REGEX(?authorLabel, "merisi", "i") ||
   REGEX(?authorLabel, "caravaggio", "i")
 )

 FILTER(
   REGEX(?label, "vocazione|san matteo", "i")
 )
}
This revealed ambiguity: the term “Caravaggio” also matches other historical agents such as Polidoro da Caravaggio. This shows that string matching is not reliable for author disambiguation.

Query 3 — Identity-based filtering (final resolution)

To solve ambiguity, we used exact IRI matching for Michelangelo Merisi da Caravaggio. 

PREFIX rdfs: 
PREFIX arco: 

SELECT DISTINCT ?cp ?label
WHERE {
 ?cp a arco:HistoricOrArtisticProperty ;
     rdfs:label ?label ;
     a-cd:hasAuthor  .
}
The final dataset correctly isolates Caravaggio’s Saint Matthew cycle: Vocazione di S. Matteo, Martirio di S. Matteo, San Matteo e l’angelo. All ambiguity is removed, producing a clean and accurate knowledge graph representation.
