Methodology

  1. Case Study Selection
    We selected Caravaggio's "The Calling of St. Matthew" as a case study to assess how a key artwork is represented in the ArCo Knowledge Graph and to identify opportunities for semantic enrichment.
  2. Thematic Exploration
    We conducted an initial SPARQL query using keywords related to Saint Matthew to obtain all relevant cultural features and understand how the topic is represented in the database.
  3. Author Identification
    We applied author-based filtering to differentiate Caravaggio's works from those of other artists. After observing ambiguity caused by textual matching, we adopted identity-based filtering using Michelangelo Merisi da Caravaggio's unique IRI.
  4. RDF Metadata Analysis
    After identifying The Calling of Saint Matthew, we extracted all predicate-object pairs associated with the resource to analyse its semantic description and the ontologies used within ArCo.
  5. Semantic Gap Detection
    Using targeted ASK queries, we checked whether certain information was represented in the knowledge graph. We identified key knowledge gaps and examined the presence of order information, English labels, and described topic relationships.
  6. Prompt Design for LLMs
    We designed targeted prompts using few-shot and chain-of-thought prompting techniques to retrieve the missing historical and semantic information from ChatGPT and Gemini.
  7. LLM Output Evaluation
    The answers generated by both models were compared in terms of factual accuracy, completeness, judgment strategy, and suitability for knowledge graph enrichment.
  8. RDF Triple Creation
    The validated data extracted from the LLMs were transformed into RDF triples using the existing ArCo ontology where possible, ensuring semantic alignment with the knowledge graph.
  9. Website Development
    Methodology, SPARQL queries, identified gaps, LLM comparison, RDF enrichments, challenges and results were organized on the project website.
  10. Online Publication
    The completed website was prepared for publication via GitHub Pages, making the project available as an open educational resource.
